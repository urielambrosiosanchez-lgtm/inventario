# Sistema de Inventario

Sistema de gestión y control de inventario desarrollado en C# (Windows Forms).

## Funcionalidades
- Registro, actualización y consulta de productos.
- Control de existencias y stock.
- Conexión a base de datos.

## Tecnologías utilizadas
- Lenguaje: C#
- Entorno: .NET / Visual Studio
- Base de datos: MySQL / SQL Server

## Cómo ejecutar el proyecto
1. Clona o descarga este repositorio.
2. Abre el archivo `SistemaInventario.slnx` con Visual Studio.
3. Compila y ejecuta la solución presionando `F5`.
